# Конструктор контента :wbhammer:

Выберите, что хотите сделать, заполните поля и получите всё сразу: файл с кодом, текст для файла `Locales` и точное место для вашей графики. Он пишет тот же код, которому учат страницы руководства, включая шаги, о которых все всегда забывают: пулы, поля post-init и ключи текста, которые не совпадают с id.

::tool:builder::

## Как пользоваться тем, что он выдаёт

1. **Код** кладётся в папку `Code/` вашего мода, в файл с именем, указанным над блоком.
2. **Текст** кладётся в `Locales/<язык>.json`. Если такой файл уже есть, скопируйте в него только строки внутри `{ }` и следите за запятыми.
3. **Графика** кладётся ровно туда, куда говорит список. Читайте слово рядом с каждой строкой: **папка** значит папка с PNG, даже если у вас всего один кадр. Одиночный PNG там, где нужна папка, это причина номер один, почему графика не появляется :wbfacepalm:.
4. **Строка для Main.cs** кладётся внутрь `OnModLoad()`. Порядок важен: черте в вашей собственной вкладке сначала нужна вкладка, а предмету, который стоит ваш собственный ресурс, сначала нужен ресурс.

Запустите игру и загляните в лог. Если что-то не так, ссылка **Полное объяснение** под списком ведёт на страницу, где этот контент разобран подробно.

> [!TIP] Поменяйте значения по умолчанию
> Каждый id в конструкторе начинается с `my_`. Замените это на что-то своё, например `hello_` для HelloBox. Два мода, которые оба добавляют `my_trait`, дерутся за него, и побеждает только один :PESgn_Stop:.

## Чего он не делает

Конструктор выдаёт контент, который **работает**. Чего он не может, так это придумать вашу идею за вас. Где функции нужна ваша собственная логика, например черта, которая делает что-то особенное, или сила, которая делает что-то новое, он оставляет чётко отмеченное место `// your code here`. Страница за ссылкой **Полное объяснение** показывает, что туда можно вписать.
