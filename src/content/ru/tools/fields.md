# Обозреватель полей ассетов :wbwise:

У каждого ассета есть фиксированный набор полей. Это реальный список, полученный напрямую из декомпилированного кода игры.

Выберите тип ассета, отфильтруйте и нажмите на имя для копирования.

::tool:fields::

## Как читать

- **Левая колонка** - это тип. `int` означает целое число, так что `rate_birth = 0.5f` не скомпилируется. `float` принимает дробь и требует суффикс `f`, например `0.5f`. `string` принимает текст в кавычках.
- **`= value`** - это значение по умолчанию, которое игра уже даёт полю. Если оно вам подходит, не задавайте его. Меньше кода, меньше опечаток.
- **"inherited from"** означает, что поле пришло из родительского класса. Работает точно так же; просто объявлено выше. `id`, `base_stats` и `path_icon` обычно унаследованы.
- **Цепочка над таблицей** (например, `ActorTrait -> BaseTrait -> BaseAugmentationAsset -> Asset`) показывает, откуда берутся поля, от самого конкретного.

> [!WARNING] Поля - это ещё не всё
> Этот инструмент говорит вам, что поле **существует** и какого оно типа. Он не говорит, читает ли его игра в вашем случае: некоторые поля важны только для цивилизованных юнитов или только при включённом другом флаге. Если сомневаетесь, найдите ванильный ассет, который делает то, что нужно, и скопируйте его значения, см. **[Чтение кода игры](#/toolbox/reading-the-game-code)**.
