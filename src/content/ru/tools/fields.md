# Обозреватель полей ассетов :wbwise:

У каждого ассета есть фиксированный набор полей. Это реальный список, полученный напрямую из декомпилированного кода игры.

Выберите тип ассета, отфильтруйте и нажмите на имя для копирования.

::tool:fields::

## Как читать

- **Левая колонка**: тип данных (`int`, `float`, `string`).
- **`= значение`**: значение по умолчанию.
- **"inherited from"**: унаследовано от родительского класса.

> [!WARNING] Поля - это еще не всё
> Обращайтесь к **[Чтение исходного кода игры](#/toolbox/reading-the-game-code)** для проверки логики.
