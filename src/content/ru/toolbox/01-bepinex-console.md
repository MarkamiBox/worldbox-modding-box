# Живая консоль :wbvideo:

Открывать `Player.log` в Блокноте после каждого мелкого теста - это сущее мучение. (Хотя я до сих пор иногда так делаю, врать не буду :23062-durrr:). **BepInEx** открывает рядом с игрой черное окно консоли, куда лог пишется в реальном времени, так что строчка появляется ровно в тот момент, когда код до нее доходит.

Эту десятиминутную настройку ты сделаешь один раз и будешь радоваться ей всю оставшуюся жизнь моддера.

## Что такое BepInEx

Это загрузчик модов, который перехватывает запуск Unity-игр. Моддеры WorldBox используют его для трёх вещей: живой консоли, **[UnityExplorer](#/toolbox/unity-explorer)** и самостоятельного **[моддинга с BepInEx](#/toolbox/bepinex-modding)**. Мы тут цивилизованные люди и пользуемся NML, но эта консоль слишком хороша, чтобы её пропускать :trollface:. NML умеет ставить его сам, если того требует какой-то мод, но ручная установка дает тебе полный контроль над всеми параметрами.

## Как его установить

1. На [официальной странице релизов BepInEx](https://github.com/BepInEx/BepInEx/releases) спустись к блоку **Assets** и скачай архив с именем `BepInEx_win_x64_5.4.x.x.zip`. Именно в такой комбинации: **win**, **x64**, **5**. Сборки под `x86`, `unix`, `macos` и `BepInEx 6 / IL2CPP` выглядят заманчиво, но ни одна из них здесь работать не будет :PES5_Dumb:.
2. Кликни правой кнопкой по архиву → **Свойства** → поставь галочку **Разблокировать** (если она там есть), а затем распакуй его **прямо в папку WorldBox**, туда, где лежит `worldbox.exe` (стандартный путь в Steam: `C:\Program Files (x86)\Steam\steamapps\common\worldbox`, либо кликни правой кнопкой по WorldBox в Steam → **Управление** → **Просмотреть локальные файлы**). Должно получиться следующее:

```text
worldbox/
├── worldbox.exe
├── BepInEx/
├── doorstop_config.ini
└── winhttp.dll
```

3. **Запусти игру один раз и закрой.** Этот первый запуск генерирует конфигурационные файлы. Никаких видимых изменений не произойдет, и это совершенно нормально :hmm:.

## Включаем консоль

Открой файл `BepInEx/config/BepInEx.cfg` в любом текстовом редакторе, найди секцию `[Logging.Console]` и пропиши:

```text BepInEx/config/BepInEx.cfg
[Logging.Console]

## Enables showing a console for log output.
# Setting type: Boolean
# Default value: false
Enabled = true
```

Снова запусти игру. Рядом с ней откроется второе окно, в котором сразу же побегут строчки логов.

## Как читать логи

Прямо сейчас, даже когда у тебя еще нет ни одного своего мода, при старте игры ты увидишь загрузку BepInEx и NeoModLoader:

```text BepInEx console
[Info   :   BepInEx] Loading [NeoModLoader 1.x.x]
[Info   :Application] Initializing WorldBox...
[Info   :Application] [NML]: NeoModLoader initialized!
```

Если эти строки появились - поздравляю, твоя живая консоль успешно работает!

Позже, когда ты напишешь свой первый мод по руководству **[Твой первый мод](#/nml/your-first-mod)**, ты увидишь, как твой мод собирается и передает тебе привет прямо в общем потоке текста:

```text BepInEx console
[Info   :Application] 005: Compile Mod HelloBox                = 2,2480
[Info   :Application] [NML]: [HelloBox]: HelloBox is alive!
```

Три полезные привычки, которые делают консоль по-настоящему незаменимой:

- **Добавляй префикс к каждому сообщению** с именем своего мода, например `[MyMod]`, чтобы мгновенно вылавливать свои строки из общего потока.
- **Логируй начало и конец** каждого этапа инициализации. Если ты видишь "регистрация черт (trait)...", но так и не дождался "черты зарегистрированы", ты безошибочно знаешь, где именно все рухнуло.
- **Держи консоль на втором мониторе** (или на половине экрана). Видеть, как строчка вылетает в ту же секунду, когда ты кликаешь по кнопке - это самый быстрый способ отладки в мире :memes:.

## Как ты будешь ее использовать (Быстрый пример)

Когда ты подготовишь файлы мода по инструкции **[Твой первый мод](#/nml/your-first-mod)**, ты сможешь добавлять живые логи для проверки игровых событий:

```csharp Mods/HelloBox/Code/Main.cs
public void Update()
{
    if (!Config.game_loaded) return;

    // Левая кнопка мыши, один раз за клик
    if (Input.GetMouseButtonDown(0))
    {
        LogInfo("click!");
    }
}
```

Каждый клик будет моментально выводить строчку в консоль. Именно ради этой мгновенной обратной связи BepInEx и становится незаменимым инструментом!
