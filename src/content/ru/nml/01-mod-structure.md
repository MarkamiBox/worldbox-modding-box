# Структура мода :wbsavebuttonbox:

## Где живут моды

Каждый мод - это **отдельная папка** внутри директории `Mods/` в вашей папке WorldBox:

```text
C:\Program Files (x86)\Steam\steamapps\common\worldbox\Mods\
```

Если папки `Mods` там еще нет, создайте её сами: правый клик → Создать → Папку, и назовите её в точности `Mods`. Внутри неё вы создадите папку своего мода с любым придуманным вами именем.

## Как устроен мод

```text
MyCoolMod/
├── mod.json          <- Паспорт вашего мода (обязательно)
├── icon.png          <- Иконка предпросмотра мода
├── Code/             <- Папка, куда вы складываете свой код
├── Locales/          <- Файлы текстов и переводов (en.json, ru.json и т.д.)
└── GameResources/    <- Свои текстуры, иконки, пиксель-арт и звуки
```

Обязательным является только `mod.json`. Остальные папки создавайте по мере необходимости. Мод, состоящий только из `mod.json` и `Code/`, уже является полноценным рабочим модом. Пустые папки никого не впечатляют.

#### За что отвечает каждая папка

- **`mod.json`**: Удостоверение личности. Без него NML сделает вид, что вашего мода вовсе не существует.
- **`icon.png`**: Изображение предварительного просмотра, отображаемое во внутриигровом меню модов.
- **`Code/`**: Папка, где лежат все ваши файлы исходного кода `.cs` (например, `Main.cs`). **NML компилирует их автоматически при каждом запуске игры**, так что вам никогда не придется собирать `.dll` вручную или устанавливать Visual Studio.
- **`Locales/`**: Место хранения файлов локализации (например, `en.json`). Без этого все ваши предметы и черты будут отображаться в игре как сырые системные ключи.
- **`GameResources/`**: Все ваши текстуры, спрайты, иконки черт, оружия и звуки. Папка должна называться строго так, потому что именно её ищет NML. Подробнее см. **[Спрайты и ресурсы](#/nml/sprites-and-resources)**.

### Манифест мода

Файл `mod.json` необходим загрузчику NeoModLoader для идентификации вашего мода :pepeOK:. Он располагается в самом корне папки мода.

```json mod.json
{
  "name": "My-First-Mod",
  "author": "yourName",
  "version": "0.1.0",
  "description": "My mod is the best frfr",
  "iconPath": "icon.png",
  "GUID": "com.yourName.my-first-mod",
  "Dependencies": [],
  "OptionalDependencies": [],
  "IncompatibleWith": []
}
```

#### Что означают эти поля?

- **`name`**: Понятное отображаемое имя мода в списке модов внутри игры.
- **`author`**: Ваше имя пользователя или никнейм. Не стесняйтесь заявить об авторстве!
- **`version`**: Номер версии мода (например, `"0.1.0"`). Увеличивайте его при каждом выпуске обновления.
- **`description`**: Краткое описание того, что делает ваш мод. Отображается в окне сведений.
- **`iconPath`**: Относительный путь к иконке мода (обычно `"icon.png"` прямо в корне мода).
- **`GUID`**: Уникальный идентификатор вашего мода, по соглашению `com.вашеимя.имямода` строчными буквами. Это аналог паспорта: он предотвращает конфликты с модами других авторов. **Выберите его один раз и никогда не меняйте**: файл настроек игрока именуется именно по этому GUID.
- **`Dependencies`**: Список GUID других модов, которые ОБЯЗАТЕЛЬНО должны быть установлены для работы вашего мода. Если мод автономный, оставьте `[]`.
- **`OptionalDependencies`**: Моды, с которыми есть интеграция при их наличии, но которые не обязательны.
- **`IncompatibleWith`**: Список GUID модов, конфликтующих с вашим. NML предупредит игрока, если включены оба.

## Немного технической теории :elpepehacker:

Каждому моду нужен один C#-файл, говорящий: "Привет, я мод". Вот весь необходимый код:

```csharp Code/Main.cs
using NeoModLoader.api;

namespace MyCoolMod
{
    public class Main : BasicMod<Main>
    {
        protected override void OnModLoad()
        {
            LogInfo("Mod loaded successfully!");
        }
    }
}
```

Это не упрощенная демо-версия для руководства: именно с этого скелета начинается подавляющее большинство реальных модов.

#### Разбор кода

- **`using NeoModLoader.api;`**: Это как открыть ящик с инструментами перед началом работы. Вместо того чтобы каждый раз писать `NeoModLoader.api.BasicMod`, директива `using` говорит компьютеру: *"держи инструменты NML готовыми на столе"*.
- **`namespace MyCoolMod`**: Фамилия для вашего кода. В чужом моде тоже может быть класс `Main`, и пространство имен гарантирует, что они не перепутаются.
- **`public class Main`**: В C# весь код живет внутри "классов". Класс - это просто чертеж или шаблон с собственным именем.
- **`: BasicMod<Main>`**: Официальное удостоверение вашего мода. Оно сообщает NML: *"Я настоящий мод"*, а взамен NML бесплатно дает вам логирование, окно настроек и поддержку переводов. Фрагмент `<Main>` просто повторяет имя вашего класса. Выглядит необычно, но пишется всегда именно так.
- **`protected override void OnModLoad()`**: Кульминационный момент. При загрузке WorldBox загрузчик NML один раз стучится в эту дверь. Всё, что регистрирует ваш мод (черты, предметы, силы), помещается внутрь этих фигурных скобок `{ }`.
- **`LogInfo(...)`**: Выводит строчку в лог с уже подставленным именем вашего мода. Так вы убедитесь, что код вообще выполнился. См. **[Логи и отладка](#/nml/logs-and-debugging)**.

> [!TIP] Длинный путь
> В старых модах вы можете увидеть такую запись. Да, я достаточно стар, чтобы помнить времена, когда это было нормой:
> ```csharp
> public class MyMod : MonoBehaviour, IMod
> {
>     private ModDeclare _declare;
>
>     public void OnLoad(ModDeclare pModDecl, GameObject pGameObject)
>     {
>         _declare = pModDecl;
>     }
>
>     public ModDeclare GetDeclaration() => _declare;
> }
> ```
> `IMod` - это чистый интерфейс, а `BasicMod<T>` - готовый класс, который реализует его и добавляет массу удобств. Работают оба варианта, но используйте `BasicMod`, если у вас нет особых причин делать иначе :PES5_Noted:.
