# Ваш первый мод :wbchosen:

Всё в этом руководстве строится вокруг **одного-единственного мода**. Мы начнем его прямо сейчас, и каждая последующая страница будет добавлять к нему по одному файлу.

К концу руководства HelloBox будет состоять примерно из двадцати файлов, и каждую строчку вы напишете сами: черту существа и культурную черту со своей вкладкой, оружие и зачарование для него, эффект состояния, добычу, облако, плитку карты, рецепт еды, снаряд, закон мира, божественную силу с собственной кнопкой, окно, панель настроек, здание, фракцию, существо, бедствие, собственный ИИ и даже патч Harmony, чтобы обойти правило, которое игра считала незыблемым.

Это намного больше, чем нужно любому настоящему моду, и именно в этом весь смысл. Вы возьмете те две или три части, которые вам действительно нужны, а остальное удалите :PES4_DeleteThis:.

Наш мод называется **HelloBox**. Давайте создадим его.

> [!NOTE] Никогда раньше не программировали?
> Ничего страшного. Читайте пояснения "что делает эта строка" под каждым блоком и копируйте код точь-в-точь. Программирование на 90% состоит из копирования того, что уже работает, с изменением одной вещи за раз :PES2_Legit:.

> Если создавать файлы руками не хочется, возьмите пустой каркас и переходите к шагу 4. Прочитать следующие три шага всё равно стоит: они объясняют, что внутри.

## 1. Создайте папку

Перейдите в папку WorldBox (ту, где лежит `worldbox.exe`), откройте `Mods/` и создайте там папку с именем `HelloBox`. Внутри неё создайте папку с именем `Code`.

```text Where it goes
worldbox/
└── Mods/
    └── HelloBox/          <- ваш мод
        ├── mod.json       <- паспорт мода (следующий шаг)
        └── Code/          <- здесь будут жить ваши .cs файлы
```

## 2. Паспорт мода: mod.json

Создайте файл `mod.json` в папке `HelloBox/` и вставьте следующее содержимое. Замените `author` на ваше имя:

```json Mods/HelloBox/mod.json
{
  "name": "HelloBox",
  "author": "yourName",
  "version": "0.1.0",
  "description": "My first WorldBox mod, built while following the guide.",
  "GUID": "com.yourName.hellobox"
}
```

- **`name`** - это имя, которое игроки увидят в списке модов.
- **`GUID`** - уникальный идентификатор. Используйте `com.вашеимя.hellobox` и больше никогда его не меняйте.

Без этого файла NML будет вести себя так, будто вашего мода не существует :pepeno:.

> [!WARNING] Блокнот попытается назвать его `mod.json.txt`
> В диалоге сохранения установите **Тип файла** в значение **Все файлы (*.*)** перед вводом имени. Затем проверьте в Проводнике: если вы не видите часть `.json`, включите **Вид → Расширения имен файлов**, чтобы Windows перестала их скрывать. Файл с именем `mod.json.txt` невидим для NML, и на эту уловку попадаются почти все новички :PESgn_Oops:.

## 3. Код: Main.cs

Создайте файл `Code/Main.cs` и вставьте следующий код:

```csharp Mods/HelloBox/Code/Main.cs
using NeoModLoader.api;

namespace HelloBox
{
    public class Main : BasicMod<Main>
    {
        protected override void OnModLoad()
        {
            LogInfo("HelloBox is alive!");
        }
    }
}
```

### Что делает каждая строка

- **`using NeoModLoader.api;`**: "Я хочу использовать инструменты NML в этом файле". Без этого компьютер не поймет, что такое `BasicMod`.
- **`namespace HelloBox`**: фамилия для вашего кода, чтобы ваш класс `Main` никогда не конфликтовал с классом `Main` из другого мода.
- **`public class Main : BasicMod<Main>`**: ваш мод. Часть `: BasicMod<Main>` означает "я мод для NML, дайте мне готовые удобства" (логирование, настройки, локализацию).
- **`protected override void OnModLoad()`**: дверь, в которую NML стучится при запуске игры. Всё, что настраивает ваш мод, помещается внутри этих фигурных скобок `{ }`.
- **`LogInfo(...)`**: выводит строку в лог с уже подставленным именем вашего мода. Именно так вы узнаете, сработал ли ваш код.

## 4. Запустите игру

Запустите WorldBox и откройте окно **Mods** в главном меню. **HelloBox** должен появиться в списке и уже быть включен. Мод, который вы положили в `Mods/` вручную, включается автоматически при первом обнаружении NML.

В этом же окне вы сможете при желании **отключить** мод позже. Клик по иконке переключает состояние, и большинству модов для вступления изменений в силу требуется перезапуск игры.

> [!TIP] Мода вообще нет в списке?
> Значит, NML его просто не увидел. В девяти случаях из десяти файл называется `mod.json.txt` вместо `mod.json`, либо папка лежит где-то за пределами `worldbox\Mods/`.

## 5. Проверьте лог

Ваша строка должна появиться в лог-файле:

```text Player.log
[NML]: [HelloBox]: HelloBox is alive!
```

Чтобы найти этот файл, вставьте следующий путь в адресную строку Проводника Windows:

```text
%USERPROFILE%\AppData\LocalLow\mkarpenko\WorldBox
```

Откройте файл `Player.log` в Блокноте и нажмите **Ctrl+F**, чтобы найти `HelloBox`.

Если вы видите эту строку - поздравляем, теперь вы моддер :PESgn_Congrats:. Если нет, откройте страницу **[Логи и отладка](#/nml/logs-and-debugging)**, она создана ровно для таких случаев.

## 6. Как устроены все последующие страницы

Начиная с этого момента, каждая страница руководства будет давать вам **один новый файл** в папке `Code/` и **одну новую строку** в методе `OnModLoad`. Шаблон всегда абсолютно одинаков:

```csharp Mods/HelloBox/Code/Main.cs
protected override void OnModLoad()
{
    LogInfo("HelloBox is alive!");

    HelloTraits.Initialize();   // добавлено страницей Кастомные черты
    HelloItems.Initialize();    // добавлено страницей Кастомные предметы
    // ...и так далее
}
```

Каждый новый файл будет выглядеть следующим образом:

```csharp Mods/HelloBox/Code/HelloSomething.cs
namespace HelloBox
{
    public static class HelloSomething
    {
        public static void Initialize()
        {
            // код с соответствующей страницы помещается сюда
        }
    }
}
```

> [!TIP] Делайте по одной вещи за раз
> Добавьте один файл, запустите игру, проверьте лог и только после этого двигайтесь дальше. Если добавить пять вещей сразу и игра сломается, у вас будет пять подозреваемых. Если добавлять по одной - виновник всегда очевиден :aPES_Detect:.
