# アセットフィールドブラウザ :wbwise:

各アセットが持つフィールドの正確な一覧です。

アセットタイプを選択し、検索してクリックでコピーできます。

::tool:fields::

## 見方

- **左の列**は型です。`int` は整数なので、`rate_birth = 0.5f` はコンパイルできません。`float` は小数を取り、`0.5f` のように接尾辞 `f` が必要です。`string` は引用符で囲んだテキストを取ります。
- **`= value`** は、ゲームがそのフィールドにすでに与えているデフォルト値です。デフォルトで良ければ、設定しないでください。コードが減れば、タイプミスも減ります。
- **"inherited from"** は、そのフィールドが親クラスから来ていることを意味します。動作はまったく同じで、上の階層で宣言されているだけです。`id`、`base_stats`、`path_icon` はたいてい継承されたものです。
- **表の上のチェーン**（例：`ActorTrait -> BaseTrait -> BaseAugmentationAsset -> Asset`）は、フィールドがどこから来るかを、具体的なものから順に示します。

> [!WARNING] フィールドがすべてではない
> このツールは、フィールドが**存在する**ことと、その型を教えてくれます。あなたのケースでゲームが実際にそれを読むかどうかは教えてくれません：文明ユニットでしか意味のないフィールドや、別のフラグがオンのときだけ意味を持つフィールドもあります。迷ったら、やりたいことをしているバニラのアセットを探して値を真似しましょう。**[ゲームのコードを読む](#/toolbox/reading-the-game-code)** を参照してください。
