# コンテンツビルダー :wbhammer:

作りたいものを選んで欄を埋めれば、全部そろいます：コードのファイル、`Locales` ファイル用のテキスト、そして画像を置く正確な場所。ガイドの各ページが教えているのと同じコードを書き、プール、post-init のフィールド、IDと一致しないテキストキーなど、みんながいつも忘れる手順も含みます。

::tool:builder::

## 出てきたものの使い方

1. **コード**はmodの `Code/` フォルダに、ブロックの上に表示された名前のファイルとして入れます。
2. **テキスト**は `Locales/<言語>.json` に入れます。そのファイルがもうあるなら、`{ }` の内側の行だけをコピーして、カンマに気をつけてください。
3. **画像**はリストのとおりの場所に置きます。各行の横の言葉を読んでください：**フォルダ**はPNGを入れたフォルダのことで、1フレームしかなくてもフォルダです。フォルダが必要な場所にPNGを1枚だけ置くのが、画像が表示されない理由の第1位です :wbfacepalm:。
4. **Main.cs の行**は `OnModLoad()` の中に入れます。順番が大事です：自分のタブに入る特性（trait）にはタブが先に必要で、自分の資源（resource）を消費するアイテムには資源が先に必要です。

ゲームを起動してログを確認しましょう。何かおかしければ、選択欄の下にある**詳しい説明**のリンクから、その内容を詳しく扱うページに行けます。

> [!TIP] デフォルト値は変えよう
> ビルダーのIDはすべて `my_` で始まります。HelloBoxの `hello_` のように、自分だけのものに変えてください。2つのmodが両方 `my_trait` を追加すると取り合いになり、勝つのは片方だけです :PESgn_Stop:。

## テンプレート

選択欄の最後のグループ **Templates** は動き方が違います。クリーチャー、建物（building）、災害（disaster）、AI、陰謀（plot）、ウィンドウは、ほとんどが自分のロジックなので、フォームで代わりに書くことはできません。代わりに、ガイドのページにある動くファイルを、あなたの名前空間と接頭辞に書き換えたものが出てきます。そのままでコンパイルして動き、**詳しい説明**のリンク先のページが1行ずつ説明しているので、どこを変えればいいか分かります。

## できないこと

ビルダーがくれるのは**動く**コンテンツです。できないのは、あなたのアイデアを代わりに考えることです。特別なことをする特性や、新しいことをするパワー（GodPower）のように、自分のロジックが必要な部分には、はっきり印のついた `// your code here` の場所を残します。そこに何を書けるかは、**詳しい説明**のリンク先のページで分かります。
