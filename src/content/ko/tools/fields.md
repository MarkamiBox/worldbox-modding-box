# 에셋 필드 브라우저 :wbwise:

게임 내 모든 에셋의 실제 필드 목록입니다.

에셋 유형을 선택하고 필터링하여 복사할 수 있습니다.

::tool:fields::

## 설명

- **왼쪽 열**: 데이터 유형 (`int`, `float`, `string`).
- **`= 기본값`**: 게임 기본값.
- **"inherited from"**: 상위 클래스 상속 필드.

> [!WARNING] 참고 사항
> 자세한 내용은 **[게임 코드 읽기](#/toolbox/reading-the-game-code)** 를 확인하세요.
