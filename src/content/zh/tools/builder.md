# 内容生成器 :wbhammer:

选好你想做的东西，填好格子，你就能拿到全部内容：代码文件、要放进 `Locales` 文件的文本，以及美术资源该放的确切位置。它写出的代码和指南各页教的完全一样，包括大家总会忘掉的步骤，比如池（pool）、post-init 字段，以及和 id 对不上的本地化键。

::tool:builder::

## 怎么用它给你的东西

1. **代码**放进你 mod 的 `Code/` 文件夹，文件名就是代码块上方显示的那个。
2. **文本**放进 `Locales/<语言>.json`。如果你已经有这个文件，只复制 `{ }` 里面的那几行进去，注意逗号。
3. **美术资源**严格按列表说的位置放。看清每一项旁边的字：**文件夹**表示一个装 PNG 的文件夹，哪怕你只有一帧。该放文件夹的地方只放了一张 PNG，是美术资源不显示的头号原因 :wbfacepalm:。
4. **Main.cs 的那一行**放进 `OnModLoad()` 里。顺序很重要：放在你自己标签页里的特质需要先有标签页，消耗你自己资源的物品需要先有资源。

启动游戏看看日志。如果哪里不对，选择框下面的**完整说明**链接会带你去详细讲解这类内容的页面。

> [!TIP] 改掉默认值
> 生成器里的每个 id 都以 `my_` 开头。改成你自己的前缀，比如 HelloBox 用的 `hello_`。两个都加了 `my_trait` 的 mod 会抢同一个 id，最后只有一个能赢 :PESgn_Stop:。

## 模板

选择框里的最后一组 **Templates** 用法不同。生物、建筑、灾难、AI、阴谋和窗口，主要都是你自己的逻辑，没有哪个表单能替你写出来。所以你拿到的是指南页面里那份能直接运行的文件，已经换成了你的命名空间和前缀。它原样就能编译运行，**完整说明**链接指向的页面会逐行讲解，让你知道该改哪里。

## 它不做什么

生成器给你的是**能用**的内容。它做不到的，是替你想出你的点子。当某个功能需要你自己的逻辑时，比如一个有特殊效果的特质，或者一个做新鲜事的神力，它会留一个标得清清楚楚的 `// your code here` 位置。**完整说明**链接指向的页面会告诉你那里可以写什么。
