# Explorateur de champs d'asset :wbwise:

Chaque asset possède une liste fixe de champs. Cette liste provient directement du jeu décompilé.

Choisissez le type d'asset, filtrez et cliquez pour copier.

::tool:fields::

## Guide de lecture

- **Colonne de gauche**: type de données (`int`, `float`, `string`).
- **`= valeur`**: valeur par défaut.
- **"inherited from"**: champ hérité d'une classe parente.

> [!WARNING] Les champs ne font pas tout
> Vérifiez l'utilisation réelle dans le code via **[Lire le code du jeu](#/toolbox/reading-the-game-code)**.
